## 1. Project Overview & Architecture Status

Tuck is a local-first, privacy-respecting bookmarking and personal memory vault for Android. The architecture is written in modern **Kotlin 2.0**, using **Jetpack Compose (Material 3)**, **Hilt Dependency Injection**, **Room ORM (SQLite)**, **WorkManager**, **Kotlin Coroutines / Flows**, and **ML Kit**.

### 1.1 Summary of Modules & File Counts
- **Kotlin Source Files:** 52
- **Unit Test Files:** 6
- **Android Manifest & Resource Files:** 5 (`AndroidManifest.xml`, `themes.xml`, `strings.xml`, `file_paths.xml`, etc.)
- **Room Database Version:** v2 (Migration to v3 planned for M2)
- **Dead Expo Artifacts:** Removed (8 items deleted in M0)

## 3. Findings & Technical Debt Checklist

1. **Destructive Migration Risk:** `DatabaseModule.kt` uses `.fallbackToDestructiveMigration()`. This must be removed before Schema v3 is deployed to prevent accidental data loss.
2. **Tab Hierarchy Realignment:** Current bottom navigation has 5 tabs (`Home`, `Search`, `Categories`, `Favorites`, `Settings`). The target specification specifies 4 tabs (`Home`, `Inbox`, `Collections`, `Search`) with a global FAB `+` and Settings in the top bar.
3. **Structured Comment Tree:** Currently `saved_items.commentsJson` stores comments in a flat JSON array. Schema v3 will migrate this into `source_posts` and `source_comments` with materialized path trees (`0001.0002`).
4. **Git Repository Uninitialized:** Clean `.gitignore` and `git init` baseline is required.
