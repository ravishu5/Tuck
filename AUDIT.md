# Tuck Codebase Audit (Milestone 0)

This audit documents every Kotlin source file in the repository, explaining its current functionality, architectural evaluation, and whether it should be **KEPT**, **REFACTORED**, or **REPLACED** in accordance with the Tuck Architecture Specification.

---

## 1. Domain Layer (`com.tuck.app.domain`)

### Models (`com.tuck.app.domain.model`)

| File | Purpose | Verdict | Rationale |
|---|---|---|---|
| `ContentType.kt` | Enum defining types of saved items (`URL`, `IMAGE`, `MULTI_IMAGE`, `PDF`, `TEXT`, `VIDEO`, `DOCUMENT`). | **REFACTOR** | Add missing content types (`AUDIO`, `LOCATION`, `CONTACT`) required for M1 rich share support. |
| `ProcessingStatus.kt` | Enum representing background processing status (`PENDING`, `PROCESSING`, `READY`, `FAILED`). | **KEEP** | Standard state machine for async enrichment pipeline. |
| `SavedItem.kt` | Domain model for saved items including tags, collections, entities, comments, and media. | **REFACTOR** | Transition single media fields (`localFilePath`, `thumbnailPath`) to a list of `MediaAsset`s (`List<MediaAsset>`), add `isPinned`, and support structured `sourcePosts`/`sourceComments`. |
| `Collection.kt` | Domain model for collections (folders) and smart collections. | **KEEP** | Clean representation of collections with smart collection metadata. |
| `Tag.kt` | Domain model for item tags. | **KEEP** | Simple tag entity (`id`, `name`, `isAutoGenerated`). |
| `Entity.kt` | Domain model for detected entities (`PHONE`, `EMAIL`, `URL`, `DATE`, `LOCATION`, `MONEY`, `HASHTAG`). | **KEEP** | Well-designed entity model with action triggers. |
| `SearchFilter.kt` | Value object containing filter criteria for queries. | **REFACTOR** | Expand to support query DSL AST, date ranges, and smart collection query filters (M5). |
| `SearchResult.kt` | Encapsulates search result item, match score, and snippet with match highlights. | **KEEP** | Clean domain representation for search results. |
| `SortOrder.kt` | Enum for sorting criteria (`RELEVANCE`, `NEWEST`, `OLDEST`, `RECENTLY_OPENED`). | **KEEP** | Used across search and feed sorting. |

## 2. Database & Data Layer (`com.tuck.app.data`)

### Room Entities (`com.tuck.app.data.local.db.entity`)

| File | Purpose | Verdict | Rationale |
|---|---|---|---|
| `SavedItemEntity.kt` | Primary table entity for `saved_items` in Room v2. | **REFACTOR** | Update table schema to v3: remove `commentsJson` (move to `source_comments`), remove single `localFilePath`/`thumbnailPath` (move to `media_assets`), add `is_pinned`. |
| `SavedItemFtsEntity.kt` | Virtual FTS4 table entity for full-text search. | **REPLACE** | Replace FTS4 with an external-content **FTS5** virtual table (`search_documents_fts`) backed by `search_documents` and SQLite sync triggers per §5.2. |
| `CollectionEntity.kt` | Room entity for `collections` table. | **KEEP** | Maps directly to schema v3 `collections` table. |
| `SavedItemCollectionCrossRef.kt` | Cross-reference table for item-collection many-to-many. | **REFACTOR** | Rename to `item_collections` to match target schema v3 convention. |
| `TagEntity.kt` | Room entity for `tags` table. | **REFACTOR** | Normalize into `item_tags` table with `(item_id, tag)` composite key. |
| `SavedItemTagCrossRef.kt` | Cross-reference table for item-tag many-to-many. | **REPLACE** | Merged into `item_tags`. |
| `EntityEntity.kt` | Room entity for `entities` table. | **REFACTOR** | Rename to `item_entities` with foreign key cascade to `saved_items`. |
| `SearchHistoryEntity.kt` | Room entity for recent search history queries. | **KEEP** | Fits target search history tracking schema. |
